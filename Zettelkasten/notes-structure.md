## Nomenclature

`STATE: D`: Dynamic, the note changes over time
`STATE: I`: Incomplete note
`STATE: C`: Complete note

`SOURCE: [file-link](path)`: Information source

## Definition of Done

The first state of a note is incomplete, if information can be added continuously, then is a `dynamic note` otherwise, it will be marked as complete.
