# C Program Structure

STATE: I

A C program, whatever its size, consists of [functions](./functions.md) and [variables](./variables.md)

## Add a library

```C
#include <library>
```

## [Functions](./functions.md)

Every C program **must have** the `main` function that returns a integer value to the [OS](./@Operating-Systems.md):

```C
int main(){
    return 0;
}
```
