# Output Console

STATE: D

SOURCE: [C Book](/Resources/Documents/C-book.pdf)

## Basics

### What is it?

A [function](./functions.md)

### How does it work?

It receives data as parameters to print them to the [CLI](./command-console-interface.md)

### What is it used for?

Print the relevant program information. For example, the program interface, success process, errors, etc.
